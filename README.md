# Abhin Rag weds Arathi | Kerala Hindu Wedding Celebration 🌸🪔

An authentic, elegant, and interactive Kerala Hindu Wedding Invitation website created with cutting-edge 3D transitions, rich cultural aesthetics, and deep attention to detail.

---

## 🌟 Key Highlights & 3D Interactive Features

1. **Three.js 3D Floating Petals & Gold Dust Canvas (`ThreeBackground.jsx`)**:
   - Realistic 3D Marigold petals and fragrant White Jasmine (Mullapoo) petals gently tumbling in 3D space with natural sway physics.
   - Golden dust particles catching light with mouse-reactive 3D parallax depth.

2. **3D Interactive Royal Invitation Envelope (`HeroEnvelope3D.jsx`)**:
   - Kerala Kasavu-bordered royal envelope with animated Nilavilakku (traditional oil lamp) glowing flame.
   - Interactive 3D unfolding experience: clicking triggers an auspicious flower petal shower (confetti) and begins the traditional temple music.

3. **Auspicious Raga & Nadaswaram Synthesizer (`audioSynth.js`, `AudioPlayer.jsx`)**:
   - Zero-dependency, 100% offline Web Audio API synthesizer playing sacred Carnatic Raga Mohanam melodies, tambura drone, and resonance of traditional Kerala bronze temple bells.
   - Floating audio widget with animated acoustic visualizer waves, play/pause, volume slider, mute, and a bell ringing trigger.

4. **Live Muhurtham Countdown (`CountdownTimer.jsx`)**:
   - Traditional brass dial countdown timer for **Sunday, May 17, 2026, 09:45 AM (Midhunam 3, Chithira Nakshatram)**.
   - One-click **"Add to Google Calendar"** & **"Download iCal / Outlook (.ics)"** integration.

5. **3D Tilt Ceremony Cards (`Ceremonies3D.jsx`)**:
   - 3D card flips revealing ritual highlights, dress codes, timings, and map links for all 4 key celebrations:
     1. *Madhuramveppu & Haldi* (May 16)
     2. *Sangeet & Sandhya Melam* (May 16)
     3. *The Sacred Wedding & Thalikettu Muhurtham* (May 17)
     4. *The Royal 28-Course Kalyana Sadya* (May 17)
     5. *Grand Evening Reception at Bolgatty Palace* (May 17)

6. **Interactive 3D Virtual Plantain Leaf Sadya (`SadyaInteractive3D.jsx`)**:
   - Interactive Kerala banana leaf banquet.
   - Click/hover on 8+ iconic dishes (Palada Pradhaman, Parippu & Golden Neyyu, Avial, Olan, Puli Inji, Kaalan, Sharkara Upperi & Chips, Ada Pradhaman) to reveal their taste profile, culinary secrets, and cultural folklore.

7. **The Sacred Rites Explainer (`TraditionsExplainer.jsx`)**:
   - Beautifully illustrated cultural explanations for *Thalikettu*, *Pudavamuri*, *Maala Maattal*, and *Pradakshinam*.

8. **Traditional Dress Code Guide (`DressCodeGuide.jsx`)**:
   - Visual guide for Gents (Kasavu Mundu & Kurta) and Ladies (Kasavu Saree, Set-Mundu & Kanchipuram Temple Silk with fresh jasmine).
   - Auspicious color palette swatches and etiquette tips.

9. **Venues & Travel Guide (`VenueMaps.jsx`)**:
   - Detailed guides for **Gokulam Convention Centre** (Kaloor) and **Bolgatty Palace & Island Resort** (Kochi).
   - Transit times from Cochin Airport (COK), Ernakulam Junction/Town railway stations, and Kochi Metro.
   - Embedded Google Map view + 1-click GPS navigation.

10. **Interactive RSVP with One-Click WhatsApp Dispatch (`RSVPSection.jsx`)**:
    - Guest count, event checkboxes, dietary/wheelchair assistance, and personal blessings.
    - Saves locally and generates pre-formatted WhatsApp RSVP to the wedding coordinator.

11. **Live Blessings Wall (`WishesGuestbook.jsx`)**:
    - Guests can write heartfelt messages, tap quick-blessing Malayalam buttons, shower flower petals, and like blessings.

12. **3D Lightbox Photo Gallery (`PhotoGallery3D.jsx`)**:
    - Pre-wedding photo cards set across Alleppey backwaters, Thrissur temples, Munnar hills, and Fort Kochi.

## 🚀 How to Run Locally

```bash
# 1. Install dependencies (if not already installed)
npm install

# 2. Start the local development server
npm run dev

# 3. Open your browser at http://localhost:3000
```

To build for production:
```bash
npm run build
npm run preview
```
